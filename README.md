# Python Module 00: Basics & Fundamentals

Welcome to **Python Module 00** of the 42 Tokyo Python curriculum. This module introduces the core foundation of Python programming through garden-themed exercises.

## 🎯 Objectives

- Understand Python basic syntax, types, and standard outputs.
- Master variable assignments, string operations, and basic arithmetic.
- Work with control flow (`if`, `elif`, `else`).
- Practice iteration (`for`, `while`) and recursion.
- Use basic data structures such as lists and dictionaries.
